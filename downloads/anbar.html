داشبورد فضای ابری، روی کامپیوتر خودتان

فضای ابری‌تان (لیارا، آروان‌کلاد، Amazon S3، MinIO، گوگل درایو، Dropbox و…) را مثل یک پوشه نشان می‌دهد: آپلود، دانلود، جستجو، پوشه و حذف، با رابط فارسی. فقط روی همین کامپیوتر باز می‌شود و کلیدها از دستگاه شما بیرون نمی‌روند.

دانلود انبار (zip · ۱۰۰ KB) راه‌اندازی

راه‌اندازی

  1. Python را از python.org نصب کنید (در ویندوز تیک «Add python.exe to PATH» را بزنید).
  2. rclone را از rclone.org نصب کنید. ویندوز: rclone.exe را کنار server.py بگذارید. مک: brew install rclone · لینوکس: sudo apt install rclone
  3. zip را باز کنید. ویندوز: روی start.bat دوبار کلیک کنید. مک و لینوکس: در همان پوشه python3 server.py
  4. مرورگر روی 127.0.0.1:5572 باز می‌شود و راهنمای اتصال فضای ابری را نشان می‌دهد. فضای ابری ایرانی با VPN روشن معمولاً وصل نمی‌شود.
